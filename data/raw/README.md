# Raw data

Run `python scripts/download_data.py` from the repository root to download the source CSV files.

Source: [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)

The dataset contains anonymized commercial orders from Brazil and is distributed under the CC BY-NC-SA 4.0 license. Raw CSV files are intentionally excluded from Git because the complete download is about 126 MB uncompressed.
